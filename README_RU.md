# Связанные светом — Большое приключение v10

Совместная 2D браузерная игра для двух человек в разных городах: компьютер + iPhone. Авторитетный сервер Node.js/WebSocket. Бесплатный хостинг Render поддерживается.

## Что включено

- Основная кампания: **99 уровней, 11 тематических миров** и 11 битв с хранителями (каждый девятый уровень).
- **100-й секретный уровень** с отдельным финальным боссом открывается, когда найдено 11 спрятанных звёздных рун (по одной в каждом мире, в восьмом уровне соответствующего акта).
- **Световая связь:** сближайтесь для зарядки, нажмите G или 🔗. Энергетический канат помогает подтягивать друг друга и создаёт временный общий защитный щит. Физика считается на сервере.
- **Эмоции:** T или ♡ на телефоне. При одновременных эмоциях рядом герои получают бонус энергии. Сервер синхронизирует совместную реакцию.
- **Мини-испытания:** гонка с преследователем, полёт через энергетическое кольцо, ритмическое включение двух узлов, совместное управление парусом. Встроены в отдельные уровни в дополнение к головоломкам миров.
- **История:** диалоги и вступления к 11 мирам, журнал воспоминаний.
- **Домик:** 12 мест для 8 видов мебели. Можно украшать дом и видеть изменения с другого устройства в одной комнате; локальная копия хранится в браузере. Хранение не облачное.
- **Питомцы:** 11 коллекционных существ (по одному в 5-м уровне каждого акта), 5 экипируемых типов помощников.
- **Костюмы:** шесть цветовых тем, открываемых прохождением уровней, видны обоим игрокам.
- **Карта 99 уровней:** ведущий может выбирать любой уже открытый уровень прямо в комнате. Есть журнал и достижения.
- **Улучшенная отзывчивость:** локальное визуальное предсказание движения с ограниченными коррекциями от сервера. Физика и столкновения остаются серверными; сетевой пинг не устраняется.

## Управление

**Искра, ПК:** A/D движение; W прыжок; F рывок; G связь; T эмоция; R перезапуск уровня (ведущий).
**Эхо, ПК:** стрелки ←/→, ↑; Enter импульс; G связь; T эмоция.
**iPhone:** горизонтальный экран, слева ←/→, справа прыжок, способность, 🔗 связь и ♡ эмоция.

## Онлайн-запуск

1. Загрузите содержимое папки в GitHub. Корень проекта должен содержать `server.js`, `game-core.js`, `adventure-core.js`, `world-mechanics.js`, `package.json`, `shared/`, `public/`.
2. Render → Web Service → подключить ветку `main` → `npm install --omit=dev` → `npm start` → `Free` (если доступно).
3. У первого игрока «Создать комнату». Второй открывает ссылку приглашения в Safari. Ведущий запускает игру после подключения второго.
4. При перезапуске Render требуется новая комната. Прогресс хранится в `localStorage` браузера, а не на Render.

## Проверки

`npm test` проверяет серверные взаимодействия, все 99 базовых миссий, боссов, мини-испытания, секретный уровень, домашние предметы и двух игроков через настоящие WebSocket-соединения. Автоматические тесты не заменяют ручной плейтест уровней и Safari QA. Для высокой задержки сети рекомендуется регион сервера, минимизирующий RTT обоих игроков.

## Ограничения

Это играбельное браузерное расширение, а не коммерческая 3D-игра уровня *It Takes Two*. Комнаты хранятся в памяти сервера; нет учётных записей, облачного переноса профиля, сохранения после очистки браузера и гарантий без лагов при 500 мс RTT. UI требует дополнительного ручного тестирования на реальном iPhone.
