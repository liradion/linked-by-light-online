# Связанные светом — v11 «Живое приключение»

Браузерный онлайн-платформер для двух игроков. Искра играет с компьютера, Эхо — с iPhone; роли назначаются по порядку входа. Основная кампания: 99 уровней в 11 мирах, 11 боссов, дополнительный секретный 100-й уровень, совместные головоломки, косметика, питомцы и домик.

## Запуск

- Node.js 20+.
- `npm start` — запуск HTTP/WebSocket сервера на `PORT` (по умолчанию 3000).
- `npm test` — все автоматические регрессионные тесты.
- На Render: Web Service из репозитория, команда `npm start`, проверка `/health`, ветка `main`.
- Оба игрока открывают один и тот же URL, ведущий создаёт комнату и отправляет код или ссылку. Гостю лучше открыть Safari и повернуть iPhone горизонтально.

## Нововведения версии v11

### Онлайн и отзывчивость

- Авторитетная серверная симуляция (60 шагов в секунду) и WebSocket-снимки 20 раз в секунду.
- Входные пакеты снабжены возрастающим номером `inputSeq`, сервер подтверждает обработанный номер в `ack`.
- Визуальное клиентское предсказание управляемого героя, плавная коррекция по состоянию сервера; интерполяция второго героя адаптируется к RTT и джиттеру.
- Индикатор диагностики: FPS, RTT, джиттер, буфер отображения. Высокий RTT по-прежнему влияет на время серверной активации объектов; предсказание не отменяет задержку сети.
- Переподключение в комнату после кратковременного обрыва сохранено. Опционально можно сохранять комнаты и токены на **постоянном серверном диске** через переменную `SAVE_DIR=/absolute/persistent/path`; это позволяет восстановить роли после перезапуска процесса. Без постоянного диска комнаты исчезают при рестарте Render.

### Управление и графика

- «⚙ Настройки»: автоматический/низкий/средний/высокий режим графики, размер кнопок 44–76 px, прозрачность, вертикальный отступ, расстояние от края, уменьшение анимаций, звук, диагностика соединения.
- Геймпад через стандартный Gamepad API: левый стик/крестовина — движение, A — прыжок, B — способность, X — связь, Y — эмоция.
- Исходные клавиши: Искра `A/D/W/F`, Эхо стрелки и `Enter`, `G` — связь, `T` — эмоция. Сенсорное управление работает на мобильных устройствах.
- Процедурные атмосферные звуки для 11 миров, звуки шагов/прыжков/способностей/боссов без сторонних аудиофайлов. Звук запускается после пользовательского нажатия с соблюдением ограничений Safari.

### Приключение

- Боссы имеют 3 фазы, меняют атаку и скорость атак на низком здоровье.
- В испытаниях с парусом Искра управляет курсом, Эхо заряжает парус импульсом.
- Активная световая связь может спасти упавшего героя, если второй находится рядом и стоит на земле.
- После этапа сервер присваивает 1–3 звезды с учётом времени, падений и использования способностей; лучший результат хранится в браузере и отображается на карте. Есть короткие вступления для каждого из 11 миров и реплики, которые можно выбрать и отправить второму игроку.
- Вкладка «Сейвы» позволяет скачать и импортировать JSON-файл прогресса (открытые уровни, звёзды, косметику, секреты, питомцев, обстановку домика). Это ручная резервная копия, **не автоматическая облачная синхронизация**.

## Состояние хранения на бесплатном Render

Бесплатные экземпляры Render могут засыпать и перезапускаться. Их локальная файловая система непостоянна, поэтому `SAVE_DIR` помогает только при использовании подключённого постоянного диска; на бесплатном тарифе нельзя гарантировать сохранность серверных комнат. Прогресс в браузере сохраняется в localStorage, но при очистке данных браузера он теряется. Экспорт JSON рекомендуется для резервной копии. Полноценная облачная синхронизация между устройствами потребует базы данных, аутентификации и защищённых резервных копий — пока она не реализована.

## Проверка

- `npm test` включает тесты 99 миров, сетевой синхронизации, боссов, мини-игр, выхода на 100-й уровень, спасения световой связью, оценок и подтверждений ввода, восстановления комнаты с диска, адаптивного буфера.
- UI проверен в Chromium в моделируемом окружении на размерах ПК и iPhone. Публичный Render и реальный мобильный Safari после этой версии нужно проверить дополнительно.

## Технические принципы

Механики и физика рассчитываются только сервером. Локальное предсказание влияет только на визуальную позицию собственного персонажа. Костюмы/дом/реплики синхронизируются в рамках комнаты. Все новые настройки сохраняются на текущем устройстве.
