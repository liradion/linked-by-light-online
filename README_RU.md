# Связанные светом — онлайн-кооператив для двух игроков

**Кампания из 99 уровней (11 актов по 9 уровней) — iPhone + ПК, даже в разных городах.** Оригинальная браузерная кооперативная 2D-игра.

## Как играть после публикации

1. На компьютере откройте опубликованную HTTPS-ссылку игры и нажмите «Создать комнату».
2. Нажмите «Скопировать приглашение» и отправьте текст человеку с iPhone.
3. Второй игрок открывает эту же ссылку на iPhone (лучше в Safari), автоматически подключается к комнате и становится Эхо.
4. На ПК, когда оба подключатся, нажмите «Начать вдвоём».
5. На iPhone поверните телефон горизонтально. Управляйте кнопками ◀ ▶ ↑ ✦ на экране.

ПК (Искра): A/D — движение, W — прыжок, F — рывок через стены; R — перезапустить текущий уровень.

iPhone (Эхо): ◀/▶ — движение, ↑ — прыжок, ✦ — импульс для кристаллов. Если второй игрок играет с ПК, его клавиши: ←/→, ↑, Enter.

## Как разместить игру в интернете бесплатно через Render

**Не загружайте только HTML-файл на Netlify/GitHub Pages:** эти статические хостинги не запускают постоянно работающий игровой WebSocket-сервер. Здесь нужен Node.js Web Service.

1. Распакуйте архив **linked-by-light-online.zip**.
2. Создайте репозиторий на GitHub (например, `linked-by-light-online`) и загрузите туда содержимое папки `linked-by-light-online`: `server.js`, `game-core.js`, `package.json`, `render.yaml`, папки `public`, `shared` и прочие файлы. В корне репозитория должен лежать `package.json`, а не внутри дополнительной вложенной папки.
3. Откройте [Render](https://dashboard.render.com/) → **New** → **Web Service**. Подключите свой GitHub-репозиторий.
4. Настройки сервиса: **Runtime:** Node, **Build command:** `npm install --omit=dev`, **Start command:** `npm start`, **Instance type:** Free (если доступен). Можно использовать `render.yaml` как Blueprint-конфигурацию.
5. Дождитесь статуса **Live**. Скопируйте адрес вида `https://имя-сервиса.onrender.com`.
6. Откройте адрес на ПК и пригласите второго игрока: ссылка с кодом комнаты автоматически создаётся внутри приложения.

Игра работает по HTTPS/WSS и **не требует публичного IP, настройки роутера или VPN у игроков**. Сервер и игра размещаются на одном Render Web Service. Никаких сторонних npm-зависимостей не используется.

### Важно о бесплатном тарифе Render

На Render бесплатные Web Services могут засыпать после 15 минут без входящего HTTP/WebSocket-трафика; активные WebSocket-сообщения предотвращают засыпание. Первое открытие после сна может занять около минуты. Платформа может перезапустить бесплатный сервис, из-за чего **активные комнаты и прогресс будут потеряны** (они пока хранятся в оперативной памяти). Данные о состоянии комнаты не переносятся между несколькими экземплярами Node; используйте **один** экземпляр.

Полезная документация: [WebSockets on Render](https://render.com/docs/websocket), [Free services](https://render.com/docs/free).

## Синхронизация

- Сервер — **единственный источник истинного игрового состояния**. Только он обновляет физику движения, столкновения, интерактивные предметы, двери и переходы уровней.
- Игровой симулятор: фиксированные 60 тиков/сек; обновления координат по WebSocket: 20 кадров/сек. Браузеры рисуют до частоты своего дисплея.
- Обмен происходит через одну комнату, объединяющую ровно два подключения. У каждого игрока своя роль, ввод с ПК или iPhone и токен повторного входа, сохранённый в памяти браузера.
- Удалённый персонаж сглаживается интерполяцией; локальная экстраполяция до 45 мс влияет **только на картинку**, не на физику.
- Когда один игрок теряет связь, игра на сервере останавливается до переподключения. После обновления страницы роль восстанавливается, если тот же браузер сохранил токен.
- **Абсолютно нулевая задержка невозможна:** пинг зависит от расстояния до сервера и качества соединения. Оба пользователя видят согласованное состояние, но отдельные кадры экрана могут приходить с разницей во времени.
- Если на iPhone перейти из Safari в сторонний встроенный браузер (или удалить данные сайта), токен роли может оказаться недоступен. В этом случае создайте новую комнату. Если сервер перезапущен, также создайте новую комнату.

## Локальная проверка на одном ПК

Требуется Node.js 20+.

```bash
npm start
```

Откройте `http://localhost:3000` в двух вкладках браузера. На первой создайте комнату, во второй откройте ссылку с её кодом. Для симуляции iPhone включите в браузере инструменты разработчика → режим мобильного устройства. Два устройства в одной Wi-Fi сети также могут подключаться по локальному IP компьютера: `http://IP_ПК:3000` (если брандмауэр разрешает). Для разных городов требуется публичный HTTPS-хостинг.

Тесты кампании и физики:

```bash
npm test
```

## Состав проекта

- `server.js` — HTTP-сервер, WebSocket-протокол, комнаты, восстановление подключения.
- `game-core.js` — игровая физика и логика на стороне сервера.
- `shared/stages.js` — общие описания трёх уровней.
- `public/index.html` — адаптивный интерфейс с iPhone-кнопками.
- `public/client.js` — сетевой клиент, сглаживание, эффекты, визуализация.
- `render.yaml` — конфигурация для Render.
- `tests/game.test.js` — тесты головоломок и переходов.

## Текущие ограничения

Это играбельный прототип, а не коммерческая игра. Прогресс уровня хранится в памяти сервера; голосового чата и аккаунтов нет. Система команд с минимальной серверной задержкой снижает рассинхронизацию, но качество связи всё равно влияет на ощущение управления. Для постоянной эксплуатации можно добавить отдельное хранилище игровых комнат, статистику и масштабирование сервера.

## Кампания из 99 уровней

- В игре **99 уровней**, организованных в **11 актов по 9 испытаний**. В каждом акте есть совместные плиты, стены для рывка Искры, кристаллы Эхо, мосты, пропасти и дополнительные опасности.
- Два кристалла на поздних уровнях стоят достаточно далеко друг от друга и требуют двух отдельных активаций.
- Уровни воспроизводимы: генератор не меняет геометрию между сервером и клиентом, оба используют `shared/stages.js`.
- **Контрольные точки:** достигнутый уровень сохраняется в `localStorage` браузера. В стартовом меню можно выбрать «Продолжить с уровня …» или «Новая игра с 1 уровня». Ведущий создаёт комнату с сохранённого уровня, а приглашённый игрок подключается к ней независимо от собственного прогресса.
- При обновлении игры или перезапуске Render текущая комната может исчезнуть; создайте новую комнату и продолжите с контрольной точки.
- Сохранение локальное: оно не синхронизируется между браузерами и исчезнет при очистке данных сайта. Для общей постоянной учётной записи потребуется отдельная база данных.
- Никакого приобретения платного сервера не требуется для хранения прогресса в браузере.

### Тестирование 99 уровней

`tests/campaign.test.js` проверяет геометрию, доступность целей, открытие ворот, переходы между уровнями, финальную победу и остановку симуляции при отключении одного игрока. Тесты используют моделирование кооперативных действий, а не ручное прохождение всех уровней человеком.


## Обновление v6 — 11 уникальных миров, 99 уникальных испытаний

Все 99 уровней делятся на 11 актов (по 9 заданий). У каждого акта своя атмосфера, интерактивные объекты и механика, а каждый из 9 уровней внутри акта использует разные положения, количество узлов, параметры и мини-финал.

| Мир | Новая механика |
| --- | --- |
| 1. Светлая долина | Два героя пробуждают собственные световые цветы прикосновением. |
| 2. Сумеречный лес | Эхо выращивает световые ветви импульсом, открывая дополнительные платформы. |
| 3. Лунная пристань | Лунные фонари заряжаются во время прилива; появляются движущиеся платформы и усиленный прыжок. |
| 4. Высокие облака | Потоки воздуха по-разному влияют на героев, а воздушные перья надо собрать в прыжке. |
| 5. Сад созвездий | Звёзды включаются в определённом порядке; неверный импульс сбрасывает последовательность. |
| 6. Кристальный разлом | Янтарные призмы реагируют на рывок Искры, голубые — на импульс Эхо. |
| 7. Сияющий город | Парные генераторы активируются способностями своих героев; поднимаются лифты. |
| 8. Река небес | Течение влияет на движение; два игрока синхронно заряжают якоря потока. |
| 9. Часовая башня | Эхо запускает часы, на ограниченное время открывая дверь, которую должны пройти оба. |
| 10. Дальний горизонт | Дальние маяки требуют точной совместной активации в заданной последовательности. |
| 11. Сердце созвездия | Ядра разных типов: Искра, Эхо или одновременное присутствие обоих. |

**Серверная архитектура:** `world-mechanics.js` управляет взаимодействиями и физическими платформами только на сервере; игровой клиент получает состояние через прежние WebSocket-снимки. Логика синхронизации не разделяется на независимые симуляции.

**Графика:** `public/biomes.js` добавляет 11 разных палитр и пространственных композиций — лес, облака, лунная вода, кристальные пики, небесные реки, шестерёнки, неоновые башни и др. Для каждого 9-го уровня предусмотрены особые эффекты финала акта.

**Проверка:** `npm test` запускает 17 регрессионных тестов: базовые платформенные правила, две WebSocket-сессии, сохранение роли, прохождение всех 99 уникальных механик и открытие ворот при выполнении совместных заданий.

**Важно:** автоматизированные проверки подтверждают логику, но не заменяют ручной плейтест всех 99 уровней. Бесплатный Render может перезапускать игру: прогресс сохраняется локально в браузере создателя комнаты, но активная комната сбрасывается.
