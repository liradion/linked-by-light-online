# Связанные светом — устанавливаемое приложение (PWA v14)

Это **Progressive Web App**, не бинарный IPA/EXE: один адрес игры работает на Windows и iPhone. После установки игра запускается в отдельном окне, получает собственный значок и обновляется с Render.

## iPhone / iPad

1. В Safari откройте https://linked-by-light-online.onrender.com/
2. Нажмите **Поделиться** → **На экран Домой**.
3. Включите **«Открыть как веб-приложение»** (если есть) и нажмите **«Добавить»**.
4. Запустите «Связанные светом» с главного экрана и поверните iPhone горизонтально.

> Встроенный браузер мессенджера может не показывать «На экран Домой». Откройте ссылку именно в Safari.

## Windows 10/11

1. Откройте https://linked-by-light-online.onrender.com/ в Chrome или Edge.
2. Нажмите **⬇ Приложение** в игре либо значок установки в адресной строке браузера.
3. Подтвердите установку. Игра откроется в отдельном окне, её можно закрепить в «Пуск»/панели задач.

## Сохранения и Google Login

- Данные синхронизируются с сервером через HTTPS и WebSocket как в браузере.
- Сервис-воркер **не перехватывает** /api/*, WebSocket и OAuth-коды. Данные комнат, Google-куки и профили не сохраняются в Cache Storage.
- Google OAuth использует внешнее перенаправление. На iOS установленное веб-приложение может передать авторизацию Safari; повторный вход в standalone-контекст зависит от версии iOS. Если вход Google не завершается, откройте игру и войдите через Safari до установки; не рассчитывайте на перенос cookie между браузером и PWA без проверки.
- Гостевой вход в комнату работает без Google. Если нужна постоянная поддержка собственного iOS OAuth-контекста, потребуется нативная оболочка и дополнительная проверка Universal Links / ASWebAuthenticationSession.

## Офлайн и обновления

Онлайн-кооператив **не работает без интернета**. При разрыве соединения появится безопасный автономный экран с кнопкой повтора. Облачный прогресс не удаляется.

Сервис-воркер хранит только офлайн-страницу и значки. Страница игры, клиентский JavaScript, запросы сохранений и OAuth всегда запрашиваются через сеть. Это исключает запуск устаревшей версии игрового движка из PWA-кэша.

При выпуске следующей версии обновите версию service worker cache и query string скриптов. Для проверки актуальности откройте DevTools → Application → Manifest и Service Workers.

## Нативные приложения

- **iOS App Store / IPA**: нужны macOS, Xcode, аккаунт Apple Developer, подпись и сборка; этот репозиторий не содержит готового IPA.
- **Windows Microsoft Store / EXE**: потребуется отдельная упаковка PWA (например PWABuilder, MSIX) и подписывание.
- PWA уже даёт независимое окно игры и значок, но не гарантирует все функции нативных приложений (особенно авторизацию через внешний браузер).

## Проверка сервера

- /app.webmanifest — JSON-манифест с правильным Content-Type.
- /icons/icon-192.png и /icons/icon-512.png — настоящие PNG с корректными размерами.
- /apple-touch-icon.png — PNG 180×180.
- /sw.js — no-store и корректная регистрация в безопасном контексте.
- /api/cloud/status — всегда сеть, никаких персональных данных в кэше.
