# Linked by Light — Product vision and positioning

**Player promise:** two people, in different places or on different devices, can discover and overcome meaningful co-op challenges together.

## Audience hypotheses
1. Long-distance partners seeking a warm, accessible shared activity.
2. Friends seeking small cooperative puzzles, not high-precision competitive platforming.
3. Indie audiences attracted by atmosphere, companion characters and shared discovery.

Do not target solely romantic partners: the product must be welcoming to friends and family too.

## Pillars
- **Together, never spectators:** both players have meaningful agency and purpose.
- **Easy to join:** join from invitation in under a minute if the server is ready; clear recovery if it is not.
- **Readable world:** two visually distinct heroes, obvious hazards, controlled motion and clean HUD.
- **Network is part of the product:** a failure to connect is a broken core promise.
- **Earned emotion:** short memorable cooperative moments rather than indiscriminate content quantity.

## Scope first release
- Deliver a curated 2–4-hour Windows campaign; target 30-minute public demo.
- Retain optional extras already in project only if they do not undermine core flow.
- Context-sensitive ability controls on small screens; clean-mode must not remove any essential mechanic.
- RU/EN first; expand localization only after quality assurance.
- Friend Pass and cross-store entitlements are **design targets**, not existing capabilities.
- No in-game ads, IAP store economy or public UGC feed required.

## Main UX flow
Launch → Start together / Tutorial → Choose hero → Invite (native share + link/code) → Partner joins → First tutorial puzzle → Co-op chapter → Checkpoint → Session resume → Ending → Invite to replay.

Every stage should specify: who can act, what the challenge teaches, how the second character contributes, what happens on failure, and why the player wants to continue.

## Experience KPIs / proposed validation thresholds
- ≥50 independent pairs in first external vertical-slice test.
- ≥80% begin a cooperative run without developer help.
- ≥90% successful partner joins after invitation under supported conditions.
- Majority pass first objective without developer intervention.
- ≥70% report desire to continue after demo.
- Server crash-free session objective ≥99.5% pending actual data and infrastructure budget.

These are **project goals, not observed results or industry benchmarks**.
