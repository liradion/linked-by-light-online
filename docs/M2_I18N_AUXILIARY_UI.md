# G2 — Auxiliary RU/EN UI: Cloud, Google Account, Map Editor, v21 Community Gallery

**Статус:** инженерный пакет в черновом PR #17. Публичная версия Render и `main` не затронуты. Этот пакет не закрывает локализацию всех дополнительных экранов.

## Реализовано

- **Облачный профиль:** отображение статуса сервера и синхронизации, подсказка о чувствительности 48-символьного ключа восстановления, ввод существующего ключа и уведомления об ошибках. Ключ, шифрование, локальное сохранение ключа и логика объединения достижений остались прежними.
- **Вход через Google:** состояние «гость/вошёл», информация о переносе прогресса и риске общего браузера, вход, выход, ручная синхронизация, сообщения о конфликтах. Никаких изменений OAuth-адресов, redirect URL, cookie или API.
- **Редактор и заметки:** навигация, ввод названия и кода пользовательской карты, создание комнаты по карте, редактирование платформ, экспорт/импорт кода `LL1.*`, личные записки и скриншоты. Изменение языка при открытом окне не должно удалять текст заметки или код карты.
- **v21 Community Gallery:** переход на вкладку, названия вкладок, описание, действия публикации, обновления, запуска пользовательской карты и отправки жалобы. Имена авторов и пользовательские названия карт остаются без переводов, как и сам контент.
- **Переключение языка внутри модального окна:** отдельный доступный `RU / EN` в облаке, аккаунте, редакторе, v21, графике, клавиатуре и настройках геймпада. Переключатель в общем хедере при открытом нативном `dialog.showModal()` становится неактивным (inert); теперь эту проблему обходит встроенный селектор.

## Архитектура и принцип безопасности

`public/aux-locale.js` — отдельный RU/EN каталог вспомогательных интерфейсов. `GameI18n.aux(key,vars)` использует локальный язык текущего клиента; `GameI18n.mountDialogLanguage(dialog)` создаёт селектор внутри нативного диалога и подписывается на изменения языка.

Только **явно перечисленные ключи** подлежат переводу. Значения пользователя (имена и email, заметки, названия карт, приглашения, коды карты, ключи восстановления) нельзя переводить по совпадению с текстом UI. Вся пользовательская информация показывается через `textContent` или `value`, без HTML-инъекций.

Никаких изменений WebSocket-протокола, правил валидации карт, схемы сохранений v11, API Google, токенов или шифрования облака.
