# M2 G2 — v23–v26 bilingual gameplay modules

**Scope:** draft feature branch `feat/commercial-readiness-foundation` in PR #17. No changes to production, main, paid distribution, protocol 4 or save v11.

## Delivery

- `public/v23-locale.js` stores **175** exact RU→EN authored display strings. The inventory checks all 174 Cyrillic literals in `public/v23plus.js`; the extra resource covers the English-titled Endless chapter.
- `public/v23plus.js` presents language-aware UI text across the physics/boss panels, 15-level chooser, living world/NPCs, expeditions, shared kitchen, stories, replay controls, assist settings and gift invitations. Official stage names/objectives are sourced from `GameI18n.stageTitle`/`stageObjective`.
- The existing modal language control is available inside the v23–v26 dialog. Tab titles, header close action, menu launch and visible page content update on local language selection.
- User-authored event journal text is rendered through `pRaw` and is never translated. Seed values, user wishes, invite URLs, JSON replays and gameplay action payloads are preserved. Dialog text uses `textContent`, not `innerHTML`.
- Unsent gift invitation text and selected theme survive tab and language updates. The previous implementation rebuilt the panel and could discard the form before sending.

## Automated checks

- `tests/v23-language.test.js` verifies exact-copy coverage, English Cyrillic exclusion, unknown user strings, all five authoritative action families, chapter lookups, modal selector and unsent gift draft persistence.
- `e2e/v23-language.spec.cjs` traverses all four panels, exercises RU↔EN in a room and checks invite text/theme survive across changes in Chromium and WebKit.
- Existing v20/v21 localization, demo and co-op/network test suites remain required. Check the five GitHub Actions workflows on the exact final SHA; do not infer a pass from earlier candidates.
