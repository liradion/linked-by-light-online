# M2 — Настройка геймпада (G2)

**Статус:** кандидат реализации в PR #17, без публикации на Render и без физической сертификации контроллеров.

## Как пользоваться

Откройте меню игры → **🎮 Геймпад**. Подключите геймпад, выберите действие, отпустите ранее зажатые кнопки, затем нажмите новую кнопку. Нажатие для переназначения не отправляется в игру. Кнопка «По умолчанию» восстанавливает стандартные действия. Схема сохраняется локально в браузере под ключом `linked-light-gamepad-v1`.

| Действие | Стандартная кнопка |
|---|---|
| Прыжок | 0 — A / ✕ |
| Способность | 1 — B / ○ |
| Связь | 2 — X / □ |
| Эмоция | 3 — Y / △ |

Можно выбирать номера 0–7 и 10–13 стандартного Gamepad API. Кнопки 8–9 (системные Start/Select) и 14–15 (движение влево/вправо крестовиной) зарезервированы. Для разных действий нельзя использовать один и тот же номер. Левый стик и крестовина по умолчанию по-прежнему перемещают героя. Настройка общая для данного устройства и сохраняется при смене роли.

## Техническая реализация

- `public/gamepad-bindings.js`: безопасное чтение/запись схемы, конфликтные проверки, захват новой кнопки, защита от срабатывания захваченной кнопки до отпускания.
- `public/quality.js`: использует текущую схему в игровом цикле, подавляет действия при открытых диалогах, освобождает движение при отключении контроллера или ошибке Gamepad API.
- `public/play-ui.js`: переносит единственную настоящую кнопку настроек в общее меню, без дублирования обработчиков.
- `tests/gamepad-bindings.test.js`: базовая схема, сохранение, конфликты, повреждённые настройки и программные сигналы.
- `e2e/gamepad-remap.spec.cjs`: симулированный стандартный геймпад в Chromium/WebKit, захват RB для способности, подтверждение реального WebSocket-пакета, сохранение после перезагрузки, отключение и подавление ввода в диалоге.

**Не сделано / требует отдельной проверки:** физические контроллеры Xbox/PlayStation/других производителей, ОС-специфичные раскладки, обработка нескольких одновременно подключённых геймпадов, назначение движения на другие оси, вибрация, управление интерфейсом с геймпада и тестирование с пользователями с двигательными ограничениями. В автоматическом E2E используется искусственный Gamepad API; это не физический hardware QA.

Изменения не затрагивают сетевой протокол 4, сохранения серверных комнат v11, клавиатурные и сенсорные схемы.
