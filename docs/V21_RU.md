# Linked by Light v21.0 — «Навстречу друг другу»

## Назначение

Новая кооперативная глава v21 с **десятью отдельными испытаниями** (внутренние индексы 112–121) и пятнадцатью дополнительными сюжетными, домашними и общественными функциями. Все прежние уровни 0–111 остаются на местах. Клиенты Windows/iPhone используют одинаковую структуру интерфейса и WebSocket-протокол 3.

## Как начать

1. Откройте игру на Windows и iPhone. В обоих браузерах обновите страницу, чтобы загрузился v21.
2. В главном меню нажмите «✨ Новая глава v21» (или «Продолжить v21», если уже проходили).
3. Ведущий отправляет код второму игроку. Когда оба подключились, нажимает «Начать вдвоём».
4. Откройте «✧ v21 · Наш мир» или клавишу **V**; на iPhone — кнопку «✦ Действия».
5. Кнопки для конкретной головоломки находятся на вкладке «Испытания». Нужное местоположение отображено на игровом поле.

## Архитектура

- Серверная физика: 60 Гц, снимки примерно 30 Гц; архитектура v19/v20 сохраняется.
- Новый слой `v21-core.js`: только физика/проверки действий/состояние десяти типов головоломок.
- Слой `v21-social.js`: дневник, совместное творчество, сезон, неделя, материалы сообщества, проверка ролей.
- Изображение и действия: `public/v21.js`, `public/v21.css`, `shared/v21-stages.js`; на клиенте запрещён авторитетный расчёт игровых наград.
- Протокол v21: `hello { protocol:3 }`, `v21Action`, `v21Publish`, `v21GalleryList`, `v21GalleryPlay`, `v21Report`, `v21Weekly`; ответы `actionResult`, `v21State`, `v21Private`, `v21Gallery`, `v21WeeklyBoard`. При повторе `actionId` команда не выполняется.
- Личные письма передаются через `v21Private` только игрокам, не зрителям. Зрители получают лишь общую игру и публичную часть истории.
- Сообщения ограничены по длине, карты валидируются посредством `expansion.cleanBlueprint`, команды ограничены по частоте. Жалобы пока являются базовым механизмом контроля, **а не заменой ручной модерации**.

## Сохранения

Сохраняется родительский формат профиля `version:11`. Дополнительные поля `adventure.v21` содержат открытые уровни `v21-01`…`v21-10`, лучшие звёзды и время, дневник, домашний прогресс, трофеи, мелодию и картину. Старые `adventure.v20`, достижения, косметика, старые уровни и рекорды не переименованы. При загрузке старого профиля v21-поля создаются с безопасными пустыми значениями.

Серверные комнаты и таблица недели сохраняются в существующем механизме `SAVE_DIR` / зашифрованном облачном хранилище, если оно настроено. На бесплатном Render без постоянного хранилища **публичная галерея, недельная таблица и состояние комнаты могут исчезнуть после перезапуска контейнера**. Локальное и Google/Cloud-сохранение профиля игрока не являются полноценным независимым хранилищем галереи.

## Ограничения и условия коммерческой публикации

- Для массовой открытой галереи нужны административная модерация, защита от спама и система удаления по запросам. Нынешняя система жалоб пригодна только для ограниченной беты.
- Авторские карты используют безопасные платформы из существующего редактора (до восьми), без произвольного JavaScript и пользовательского исполняемого кода.
- Мелодия ограничена оригинальным восьмитоновым синтезатором, не транслирует чужую коммерческую музыку.
- Сезонные истории — короткие интерактивные текстовые сцены, не отдельные большие уровни или ролики.
- Рисование — синхронизируемая пиксельная картина 8×8, не отдельный графический редактор со слоями.
- Недельная таблица анонимна по отношению к игрокам и отражает только время, подтверждённое сервером комнаты; она не является защищённым от накруток глобальным рейтингом с независимыми аккаунтами.
- Фоторежим работает локально; сервер не хранит фотографии и не собирает личные подписи.
- Для реального релиза остаются необходимыми испытания двух устройств, тестирование доступности интерфейса, ручной QA всех десяти новых карт и юридические документы для пользовательского контента.

## Проверка

```bash
npm test
node --check v21-core.js
node --check v21-social.js
node --check public/v21.js
```

CI проверяет обратную совместимость основных WebSocket-сценариев v20 и отдельные тесты v21: прохождение каждой из десяти механик, роли, приватность записок, творчество, сезон, UGC и восстановление комнаты.

Программный лимит комнат остаётся прежним: **200**, однако нагрузочные тесты показали, что на CPU-квоте уровня Render Free нельзя гарантировать 400 одновременно играющих. Не повышать реальный лимит без отдельного мониторинга.
